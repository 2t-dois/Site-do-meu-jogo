# ⚔️ TtritoWorld

**Prepare-se, aventureiro!** 🏰

Este é um site criado para apresentar e disponibilizar o download de um jogo de RPG desenvolvido com muito carinho e dedicação.

## 🎮 Sobre o projeto

O objetivo deste site é facilitar o acesso ao TtritoWorld, oferecendo um botão para baixar o jogo e instruções para realizar a instalação corretamente, incluindo a preservação dos arquivos de salvamento.

## 📥 Download

Acesse o link abaixo para baixar o jogo:

👉 [**Baixar TtritoWorld pelo MediaFire**](https://www.mediafire.com/file/uavzu8wbcwcgdkt/TtritoWorld.ex/file)

## 🗺️ Como instalar

1. Acesse o link de download e baixe o jogo.
2. Crie uma pasta com o nome `TtritoWorld`.
3. Coloque o jogo dentro dessa pasta e execute-o pela primeira vez.
4. Verifique se a pasta `saves` foi criada. Ela é responsável por armazenar o progresso do jogo.
5. Mantenha a pasta `saves` junto dos arquivos do jogo para preservar seus salvamentos.
6. Depois disso, você pode criar um atalho do jogo na área de trabalho e começar sua aventura!
